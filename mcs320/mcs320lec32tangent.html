tangent line with interact

An Interactive Applet powered by Sage and MathJax.

MCS 320 Lecture 33

Overview

The code is adapted from Sage for Undergraduates by Gregory Bard, pages 285 in Figure 1.

Instructions

Click on the button to launch the interactive applet.

Discussion

The scale on top of the figure allows the user to move the x-coordinate of a point on a curve. After each move, the tangent line at the new point is shown.
