An alire workspace is provided.

The default configuration is for windows. To change manually, replace the occurrences of the string windows by linux in the files in the config folder.

Type alr build to build and alr clean to clean.

To test the libPHCpack, first type
cp lib/libPHCpack.* src/lib
and then navigate to the src/Julia folder and type
julia showVersion.jl
or navigate to the src/Python/PHCpy/phcpy folder and type
python version.py
